# Datasheets

| Folder | Contents |
|--------|----------|
| `ics/` | MCU, regulators, and other ICs (include the CH32V203 reference manual) |
| `passives/` | Resistors, capacitors, inductors, crystals |
| `connectors/` | USB, headers, and other connectors |
| `modules/` | Pre-built modules (if any) |
| `other/` | Everything else |

Naming: `MANUFACTURER_PARTNUMBER.pdf` (e.g. `WCH_CH32V203.pdf`). Keep the original
filename or source URL in a note if it is not obvious.
